# פרק 03 — אוספים (Collections)

> **חשוב — נתיב באנגלית בלבד.** Gradle ו-Android Studio לא מתמודדים עם עברית
> בנתיב הקובץ, ופרויקט שיושב בתיקייה עם שם עברי פשוט לא ייבנה. אל תשנו את שם
> התיקייה לעברית, ואל תחלצו לתוך תיקייה כמו `שולחן העבודה\פרויקטים`.
> נתיב מומלץ: `C:\Android\` או `C:\Users\<name>\AndroidProjects\`


פרויקט Android Studio שלם ורץ, בשפת Java, המלווה את פרק 03 של הקורס.
מערך הוא בגודל קבוע; אוסף גדל ומתכווץ לבד. כאן מדגימים בפועל את
`ArrayList`, `HashMap` ו-`HashSet`, את הגנריות (`<...>`) שמגנה על סוג האיברים,
ואת המיון בעזרת `Comparable` ו-`Comparator`.

כל דוגמה מהפרק מורצת באמת בתוך מסך משלה, והפלט מוצג ב-TextView בתוך ScrollView
במקום ב-`System.out` שאין לו מקום באפליקציה. בכל מסך יש גם אזור ניסוי חי
עם כפתורים ו-ListView, כדי לראות את האוסף משתנה מול העיניים.

## המסכים

| מסך | מה הוא מדגים |
|---|---|
| **MainActivity** | תפריט הפרק — כפתור לכל דוגמה |
| **ListDemoActivity** | `ArrayList`: הוספה בסוף ובאמצע, `contains` / `indexOf` / `get`, `set`, מחיקה לפי ערך ולפי מקום, `size` / `isEmpty` / `clear`. למטה: רשימה חיה ב-ListView |
| **MapDemoActivity** | `HashMap`: `put` (הוספה ועדכון), `get`, `getOrDefault`, `containsKey`, `remove`, ומעבר על `keySet` / `entrySet` / `values`. למטה: מפה חיה של טלפון ← שם |
| **SetDemoActivity** | `HashSet`: `add` שמחזיר `false` על כפילות, `contains` ב-O(1), `remove`, ומעבר שאינו לפי סדר ההוספה. למטה: רשימת נוכחות חיה |
| **ContactDemoActivity** | המחלקה `Contact` בתוך אוספים גנריים: `toString` (מה ש-ArrayAdapter מציג), `equals` + `hashCode` (זהות לפי טלפון), `compareTo`. אפשר להשוות שני אנשי קשר שאתם מקלידים |
| **SortDemoActivity** | מיון: `Collections.sort(list)` לפי `compareTo`, מול `Collections.sort(list, comparator)` עם `Comparator` חיצוני. הסדר משתנה ב-ListView בלחיצה. גם `searchByName` — חיפוש חלקי ב-O(n) |
| **PhoneBookActivity** | הפרויקט המסכם: ספר טלפונים המשלב `ArrayList` להצגה ולמיון עם `HashMap` לחיפוש מיידי. הוספה, חיפוש לפי מספר, מיון, ומחיקה בלחיצה ארוכה על שורה |

## מחלקות עזר

- **`Contact`** — איש קשר. מממשת `Comparable<Contact>`, וכוללת `toString`, `equals` ו-`hashCode`.
- **`PhoneBookManager`** — מנהל הנתונים. מחזיק `ArrayList<Contact>` ו-`HashMap<String, Contact>`
  ואינו יודע דבר על המסך — וזה בכוונה.

## איך מריצים

1. פותחים את התיקייה `03-Collections` ב-Android Studio (Open → בוחרים את התיקייה).
2. ממתינים ל-Gradle Sync.
3. לוחצים **Run ▶** על מכשיר או אמולטור (Android 7.0 ומעלה).

Java בלבד · `minSdk 24` · `compileSdk 36` · פריסות `LinearLayout` / `ScrollView` בלבד.

## איך מנווטים באפליקציה

- **המסך הראשון הוא תפריט הפרק** — כפתור לכל דוגמה, עם שורת הסבר מה היא מדגימה.
- **מכל מסך דוגמה חוזרים בחץ שבפס העליון** (או בכפתור החזרה של המכשיר).
  מתחת לשם המסך כתוב "← חזרה לתפריט הפרק" כדי שלא יהיה ספק.
- מאחורי החץ עומדת המחלקה `BaseActivity`: כל מסכי הדוגמה יורשים ממנה
  במקום מ-`AppCompatActivity`, ולכן קוד החזרה נכתב פעם אחת בלבד.
  זו בדיוק הירושה מפרק 2 — מה שמשותף עולה למחלקת־האב.

## העיצוב

כל הפרויקטים בקורס חולקים ערכת עיצוב אחת, שמוגדרת בשני קבצים בלבד:

| קובץ | מה יש בו |
|---|---|
| `res/values/colors.xml` | לוח הצבעים |
| `res/values/themes.xml` | ערכת הנושא וסגנונות ברירת המחדל לכפתור, טקסט ושדה קלט |

כי הסגנונות מוגדרים בערכת הנושא, **אף קובץ פריסה לא צריך לחזור עליהם** —
כל `Button` בכל מסך מקבל אוטומטית פינות מעוגלות, גובה נוח וטקסט קריא.
רוצים לשנות את מראה כל האפליקציה? משנים ערך אחד ב-`colors.xml`.
יש גם `values-night/themes.xml` — האפליקציה מתאימה את עצמה למצב לילה.
